# 北工大党校网课自动连播（油猴脚本）

针对**北京工业大学「党旗飘飘」智慧党建平台**（`rdjypx.bjut.edu.cn` / `rdyplx.bjut.edu.cn`）入党教育/预备党员培训网课的 Tampermonkey 用户脚本。

一次性点「识别目录」，之后自动逐门播完整个课程清单。

> 本脚本只模拟「人本来会做的点击」：点播、点「继续观看」、点弹窗关闭、点下一集、点下一门课。
> **不构造请求、不调用任何提交接口、不伪造学时、不碰考试页。**

## 功能

| # | 功能 | 说明 |
|---|---|---|
| 1 | 伪装页面可见 | 平台一旦发现切后台/最小化就 `player.pause()` 并弹「视频已暂停」。脚本在属性层改写 `document.hidden/visibilityState/hasFocus`，并在捕获阶段掐掉 `visibilitychange`/`blur` |
| 2 | 后台保活（三重） | ① Worker 心跳（不受后台标签页节流）② 静音音频（避免 intensive throttling）③ 画中画（需手势，面板按钮） |
| 3 | 自动切集 | 一门课内的多集（上/中/下）按侧栏顺序自动播完，`ended` 与弹窗两条路径做了防重复触发 |
| 4 | 目录识别 | 把「我的课程」页上每门课的**名字 + 真实地址 + 完成状态**抄进本地清单 |
| 5 | 防暂停 | 识别并点掉「视频已暂停」「上次观看到 xx:xx（从头开始 / 继续观看）」等弹窗 |
| 6 | 效率统计 | 面板显示「视频真实推进秒数 ÷ 现实时间」，低了说明卡顿/被限速，可据此判断是网卡还是被拦 |

v1.13 起支持**倍速**（1.0~2.0），平台把速度改回 1 会立刻掰回来。

## 安装

**推荐：从 raw 地址安装**（之后 Tampermonkey 能按版本号原地更新，不会再出现重复条目）

```
https://raw.githubusercontent.com/xuansir163/bjut-rdjypx-autoplay/main/rdjypx-autoplay.user.js
```

把上面这个地址粘进浏览器地址栏回车，Tampermonkey 会自动弹出安装页。

手工安装：

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 打开 Tampermonkey → 添加新脚本 → 全选删除模板 → 粘贴 `rdjypx-autoplay.user.js` 全部内容 → `Ctrl+S`
3. 或者把 `.user.js` 文件直接拖进浏览器窗口

> ⚠️ **升级时务必先删旧脚本条目再装新的**。通过本地文件/本地服务器安装时，Tampermonkey 是「新建条目」而不是覆盖同名脚本，会留下两份同时运行（表现为两个面板叠在一起、互相抢弹窗）。从 raw 地址安装且原脚本带 `@updateURL` 就不会有这个毛病。

## 使用

1. 登录平台，打开**「我的课程」**页（`/user/lesson`）
2. 点面板上的 **「识别目录」**
3. 不用管了

之后脚本自己：进第一门没完成的课 → 播它的视频 → 一门课的全部集数播完 → 等平台记学时 → 回「我的课程」核对 → 跳清单里下一门。

进度存在 `localStorage`，关浏览器重开接着走。

### 面板按钮

| 按钮 | 作用 |
|---|---|
| 暂停 / 继续 | 总开关 |
| 下一集 | 立即切到目录里的下一项 |
| 跳过红项 | 目录里标红的项是否跳过（**播放页侧栏标红 = 这一集已经看完**；关掉它脚本就只按"真的播到结尾"推进，不理颜色） |
| 重扫目录 | 重新读取当前页侧栏目录 |
| 自动刷课 | 课程串联层开关 |
| 清空记录 | 只清「哪门已刷完」的打勾，清单和地址都保留 |
| 识别目录 | 抄当前页的课程清单 |
| 看清单 | 在日志里逐条列出已识别的课程 |
| 倍速 | 循环 1.0 → 1.25 → 1.5 → 1.75 → 2.0，存本地 |
| 画中画保活 | 视频放进画中画小窗，最彻底的后台保活 |

### 控制台诊断

```js
__rdjypx.dump()      // 播放效率、已播集数、暂停/卡顿统计
__rdjypx.ac()        // 自动刷课层：页面类型、清单、下一门、上次跳转、面板状态
__rdjypx.acScan()    // 等同点「识别目录」
__rdjypx.why()       // 为什么没自动切集
__rdjypx.keep()      // 查看保活机制状态
__rdjypx.acBlind(true) // 老 v1.9 盲跑模式：没识别过目录也自己猜着跳
```

## 平台结构（2026-11-05 实测）

```
/user/lesson                         我的课程（每门课一张 div.study_plan2 卡片）
   ↓ 卡片里 <a class="plan_a" href="/ybdy/play?v_id=…">课名</a>
/ybdy/play?v_id=N&r_id=M&r=video     播放页（侧栏是这个 v_id 下的多集）
   ↓
/ybdy/lesson/video?lesson_id=K       选课中心（⚠️ 脚本绝不介入，那里点了就是真选课）
/ybdy/*/exam、/jjfz/lesson/exam      测试 / 考试（脚本永不介入）
```

几个反直觉的事实，代码里都按实测处理了：

- 课程页路径是 `/user/lesson`，**不是** `/jjfz/lesson`（那是同类平台另一套路由，脚本保留兼容）
- 「我的课程」页上，完成状态是卡片里的文字「已完成」（绿）/「未完成」（红）——**课程卡片上红色 = 未完成**
- 播放页侧栏正好相反：**标红 = 这一集已经看完**（用户 2026-11-05 确认）。脚本据此跳过看完的集、全部标红才算这门收尾
- 课程到底算不算完成，**只认「我的课程」页那行字**。播放页播完只记「待平台确认」，等平台结算；学时没到账时不会假装完成、也不会被永久跳过
- 打开有进度的视频会弹「温馨提示：该课程视频你上次观看到 xx:xx」，要选「继续观看」

## 已知限制

- **只有「看视频」这段被自动化**。章节测试、综合考试一律不碰。
- 保活②③依赖浏览器策略，Chrome/Edge 行为有差异，不保证全通。面板上三个保活指示都亮才是稳态。
- 倍速不保证平台照记学时：如果平台按真实流逝时间计学习时长，倍速会少记。开完自己看学时涨幅，不对就调回 1.0。
- 如果平台某门课的视频全看完还得做章节测试才解锁下一章，脚本会停在那门课，不会替你答题。
- 平台改版会让选择器失效，此时面板会显示「识别目录」为空或「这一页脚本不认识」，用 `__rdjypx.ac()` 看状态。
